# 合盖运行（LidAwake）

一个 macOS 菜单栏小工具：MacBook 合上盖子后继续运行，不进入睡眠。合盖时屏幕亮度和键盘背光自动调到 0，开盖后恢复原样。

适合合盖后继续下载、跑任务，或者用远程桌面控制这台电脑。

## 功能

- 合盖不睡眠：由菜单栏开关控制，关闭开关后恢复系统原来的睡眠设置。
- 合盖时调暗：屏幕亮度和键盘背光调到 0。屏幕本身不熄灭，所以不会触发锁屏，远程桌面画面也正常。
- 开盖恢复：屏幕亮度和键盘背光恢复到合盖前的值。
- 电池保护：可以单独设置用电池时是否合盖运行。电量低于阈值时允许睡眠，阈值可选 10%～50%，默认 30%。
- 开机自动启动：可在菜单里打开或关闭。

## 系统要求

- Apple 芯片的 MacBook，macOS 14 或更高版本。
- 已安装 Xcode 或 Xcode 命令行工具，用来编译。

只在 M1 Pro MacBook Pro、macOS 27 上测试过。

## 安装

1. 下载源码：

   ```bash
   git clone https://github.com/Mxby0609/LidAwake.git
   cd LidAwake
   ```

2. 编译并安装：

   ```bash
   ./build.sh install
   ```

   软件会安装到 `~/Applications/LidAwake.app` 并自动启动。菜单栏出现一个咖啡杯图标。

只编译、不安装时，运行 `./build.sh`，结果在 `build/` 目录。

## 使用

1. 点击菜单栏的咖啡杯图标。
2. 点击 **合盖继续运行**。
3. 第一次打开时，系统弹窗要求输入开机密码。输入后，以后切换开关不再需要密码。

打开后图标变成实心杯子。菜单第一行显示当前状态，例如“插电中，合盖继续运行”；出错时，错误信息也显示在这一行，图标变成感叹号。

菜单里的其他选项：

| 选项 | 作用 |
|---|---|
| **用电池时也运行** | 不勾选时，用电池合盖照常睡眠 |
| **电量低于 30% 时允许睡眠** | 勾选“用电池时也运行”后可用。合盖途中电量跌破阈值，电脑会主动睡眠 |
| **开机自动启动** | 登录后自动运行 |
| **退出** | 退出软件，并恢复系统原来的睡眠设置 |

## 工作原理

**禁止睡眠**

软件通过 `pmset -a disablesleep 1` 禁止睡眠。这条命令需要管理员权限。第一次授权时，软件写入 `/etc/sudoers.d/lidawake`，内容只允许当前用户免密执行这三条命令：

```text
/usr/bin/pmset -a disablesleep 0
/usr/bin/pmset -a disablesleep 1
/usr/bin/pmset sleepnow
```

写入前先用 `visudo` 校验格式，格式不对就不写入。

打开总开关时，软件记下系统原来的 `disablesleep` 值。关闭开关或退出软件时恢复这个值。软件异常退出时，这个值保存在偏好设置里，下次启动继续沿用。

**合盖检测**

软件监听系统电源管理发出的合盖通知，并读取 `AppleClamshellState` 判断盖子是否合上。

**屏幕亮度和键盘背光**

这两项没有公开接口，软件使用了系统的私有框架：

- 屏幕亮度：`DisplayServices` 框架。
- 键盘背光：`CoreBrightness` 框架的 `KeyboardBrightnessClient`。

私有框架可能在系统更新后变化，导致这两项失效。合盖不睡眠的功能不受影响。

## 已知限制

- 亮度 0 是屏幕背光的最低档，不是完全断电。合上盖子后看不到光。
- 软件不处理外接显示器，只调内置屏。

## 罗技无线鼠标的灯

合盖后，罗技无线鼠标的灯可能还亮着。鼠标闲置几分钟后会自己休眠，灯也随之熄灭。不想等的话，在 G HUB 的灯光设置里把效果改成“关闭”。

## 卸载

1. 如果打开过 **开机自动启动**，在菜单里取消勾选。
2. 点击菜单栏图标，点击 **退出**。
3. 删除软件：

   ```bash
   rm -rf ~/Applications/LidAwake.app
   ```

4. 删除授权规则：

   ```bash
   sudo rm /etc/sudoers.d/lidawake
   ```

5. 删除偏好设置：

   ```bash
   defaults delete local.mxby.lidawake
   ```
