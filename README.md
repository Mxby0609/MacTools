# Mac 小工具（MacTools）

一个 macOS 菜单栏小工具，目前有合盖运行、无人操作调暗和窗口居中三个功能，每个功能各有开关。

## 功能

**合盖运行**：MacBook 合上盖子后继续运行，不进入睡眠。适合合盖后继续下载、跑任务，或者用远程桌面控制这台电脑。

- 合盖不睡眠：由菜单栏开关控制，关闭开关后恢复合盖睡眠。
- 合盖时调暗：屏幕亮度和键盘背光调到 0。屏幕本身不熄灭，所以不会触发锁屏，远程桌面画面也正常。
- 开盖恢复：屏幕亮度和键盘背光恢复到合盖前的值。
- 电池保护：可以单独设置用电池时是否合盖运行。电量低于阈值时允许睡眠，阈值可选 10%～50%，默认 30%。

**无人操作调暗**：开着盖子，一段时间没有键盘、鼠标操作后，电脑继续运行，屏幕亮度和键盘背光调到 0；有新的操作就恢复。

- 等待时长：可选 1、2、5、10、30 分钟，默认 5 分钟。另有 5 秒一项，用来测试。
- 逐渐调暗和恢复：默认打开。屏幕、键盘背光和音量在 0.6 秒内逐渐降到最低，期间动一下鼠标或按任意键就取消。恢复时同样用 0.6 秒逐渐亮起。合盖时屏幕和键盘背光已经看不见，直接调到 0，音量同样逐渐降低；开盖时等内置屏重新上线，再逐渐亮起。
- 不熄屏、不睡眠：开关打开期间，系统不会因为无人操作而熄屏或睡眠。
- 不打断观看：别的软件要求屏幕保持点亮时不调暗，例如正在播放视频或开视频会议。
- 电池保护：和合盖运行共用同一组电池设置。

**调暗时降低音量**：可选。打开后，合盖或无人操作调暗时，音量也调到最低；恢复亮度时，音量一并恢复。

**暂停播放**：打开“调暗时降低音量”后可用，默认打开。音量降到最低后，暂停正在播放的音乐或播客。恢复时不会自动继续播放，需要你自己按一下播放。

**窗口居中**：按 `Control + Option + C`，把当前窗口移到屏幕中间，窗口大小不变。由菜单里的开关控制。

**开机自动启动**：可在菜单里打开或关闭。

## 系统要求

- Apple 芯片的 MacBook，macOS 14 或更高版本。
- 已安装 Xcode 或 Xcode 命令行工具，用来编译。

只在 M1 Pro MacBook Pro、macOS 27 上测试过。

## 安装

1. 下载源码：

   ```bash
   git clone https://github.com/Mxby0609/MacTools.git
   cd MacTools
   ```

2. 编译并安装：

   ```bash
   ./build.sh install
   ```

   软件会安装到 `~/Applications/MacTools.app` 并自动启动。菜单栏出现一个咖啡杯图标。

只编译、不安装时，运行 `./build.sh`，结果在 `build/` 目录。

## 使用

1. 点击菜单栏的咖啡杯图标。
2. 点击 **合盖继续运行**。
3. 第一次打开时，系统弹窗要求输入开机密码。输入后，以后切换开关不再需要密码。

打开后图标变成实心杯子。菜单第一行显示当前状态，例如“插电中，保持运行”；出错时，错误信息也显示在这一行，图标变成感叹号。

菜单里的其他选项：

| 选项 | 作用 |
|---|---|
| **无人操作时调暗并继续运行** | 打开或关闭无人操作调暗，不需要密码 |
| **无人操作 5 分钟后调暗** | 打开无人操作调暗后可用，在子菜单里选择等待时长 |
| **逐渐调暗和恢复** | 打开合盖运行或无人操作调暗后可用。关闭后直接调暗、直接恢复 |
| **调暗时音量也调到最低** | 合盖和无人操作两种调暗都适用 |
| **音量调到最低后暂停播放** | 打开“调暗时音量也调到最低”后可用 |
| **用电池时也运行** | 不勾选时，用电池不保持运行：合盖照常睡眠，无人操作也不调暗 |
| **电量低于 30% 时允许睡眠** | 勾选“用电池时也运行”后可用。合盖途中电量跌破阈值，电脑会主动睡眠 |
| **按 ⌃⌥C 居中当前窗口** | 打开或关闭窗口居中快捷键 |
| **授权辅助功能…** | 只在窗口居中已打开、但缺少辅助功能权限时出现。点击后打开系统设置的对应页面 |
| **开机自动启动** | 登录后自动运行 |
| **退出** | 退出软件，并恢复合盖睡眠 |

## 窗口居中

1. 点击菜单栏图标，点击 **按 ⌃⌥C 居中当前窗口**。
2. 第一次打开时，系统弹窗要求辅助功能权限。点击“打开系统设置”，在“隐私与安全性 > 辅助功能”里打开 MacTools 的开关。
3. 选中任意窗口，按 `Control + Option + C`。

窗口移到它所在屏幕的可用区域正中。可用区域不含菜单栏和程序坞，和系统自带的“窗口 > 居中”基准相同。

窗口不能移动时，电脑会响一声提示音，例如窗口处于全屏状态，或者前台软件没有窗口。

辅助功能授权和软件的签名绑定。构建脚本默认使用临时签名，每次重新编译安装后，系统会把软件当成新程序，之前的授权失效。这时按快捷键没有反应，菜单里会出现 **授权辅助功能…**。点击它，在列表里先删除旧的 MacTools，再重新添加并打开开关。

要让授权在重新编译后继续有效，创建一个固定的签名证书，只需做一次：

1. 打开“钥匙串访问”，在菜单栏选择“钥匙串访问 > 证书助理 > 创建证书”。
2. 名称填 `MacTools Dev`，身份类型选“自签名根证书”，证书类型选“代码签名”，点击“创建”。
3. 运行 `./build.sh install`。系统询问是否允许 codesign 使用这个密钥时，输入开机密码并点击“始终允许”。
4. 按上一段的方法重新授权一次辅助功能。之后再编译安装，授权不再失效。

## 工作原理

**禁止睡眠**

软件通过 `pmset -a disablesleep 1` 禁止睡眠。这条命令需要管理员权限。第一次授权时，软件写入 `/etc/sudoers.d/mactools`，内容只允许当前用户免密执行这三条命令：

```text
/usr/bin/pmset -a disablesleep 0
/usr/bin/pmset -a disablesleep 1
/usr/bin/pmset sleepnow
```

写入前先用 `visudo` 校验格式，格式不对就不写入。

关闭开关或退出软件时，软件把 `disablesleep` 设回 0。其他软件设置的禁止睡眠也会被一并取消。软件异常退出时来不及设回 0，重新启动软件后，关闭开关或正常退出即可恢复。

**合盖检测**

软件监听系统电源管理发出的合盖通知，并读取 `AppleClamshellState` 判断盖子是否合上。

**无人操作检测**

软件定时读取距离上次键盘、鼠标操作过了多久，超过设定的时长就调暗；调暗期间每 0.25 秒检查一次，发现新的操作就恢复。远程桌面发来的操作也算。

开关打开期间，软件向系统声明“无人操作时不要熄屏”，效果和 `caffeinate -d` 相同。这项声明不需要管理员权限，软件退出时自动撤销。

**音量**

软件通过系统的 Core Audio 接口调整默认输出设备的音量。恢复时调回原来那个设备，调暗期间换了耳机也不会调错。部分 HDMI 显示器等设备没有音量调节，这时音量保持不变。

**暂停播放**

暂停命令通过系统私有的 `MediaRemote` 框架发出，效果和键盘上的播放/暂停键一样，但只会暂停：没在播放时发出去不会有任何反应，不会反过来把音乐打开。

新版 macOS 不让第三方软件读取播放状态，软件无法确定暂停的是不是你正在听的内容，所以恢复时不自动继续播放。

**屏幕亮度和键盘背光**

这两项没有公开接口，软件使用了系统的私有框架：

- 屏幕亮度：`DisplayServices` 框架。
- 键盘背光：`CoreBrightness` 框架的 `KeyboardBrightnessClient`。

私有框架可能在系统更新后变化，导致这两项失效。合盖不睡眠的功能不受影响。

**逐渐调暗和恢复**

背光调到最低一档时仍然看得见，调到 0 又会一下子全黑。所以渐变时，软件同时通过系统的伽马表把画面内容按比例压暗，背光关掉那一下就看不出来。调暗完成 1 秒后，伽马表恢复原样，只保留背光为 0。软件异常退出时，系统会自动恢复伽马表。

每秒调整的次数和屏幕刷新率一致，ProMotion 屏幕是每秒 120 次。

**窗口居中**

快捷键通过 Carbon 的 `RegisterEventHotKey` 注册，注册本身不需要权限。移动窗口使用系统的辅助功能接口，这是 macOS 允许一个软件移动其他软件窗口的唯一途径，所以需要辅助功能权限。

有些窗口收到移动请求后返回成功，实际却不动。软件在移动后读回窗口位置，位置不对就按失败处理。

## 已知限制

- 亮度 0 是屏幕背光的最低档，不是完全断电。合上盖子后看不到光。
- 软件不处理外接显示器，只调内置屏。
- 打开无人操作调暗后，系统不再自动熄屏。如果锁屏依赖熄屏触发，也就不会自动锁屏。
- 窗口居中的快捷键固定为 `Control + Option + C`，不能在菜单里修改。
- 窗口比屏幕可用区域还高时，窗口顶边贴住菜单栏下沿，不再上下居中。

## 罗技无线鼠标的灯

合盖后，罗技无线鼠标的灯可能还亮着。鼠标闲置几分钟后会自己休眠，灯也随之熄灭。不想等的话，在 G HUB 的灯光设置里把效果改成“关闭”。

## 卸载

1. 如果打开过 **开机自动启动**，在菜单里取消勾选。
2. 点击菜单栏图标，点击 **退出**。
3. 删除软件：

   ```bash
   rm -rf ~/Applications/MacTools.app
   ```

4. 删除授权规则：

   ```bash
   sudo rm /etc/sudoers.d/mactools
   ```

5. 删除偏好设置：

   ```bash
   defaults delete local.mxby.mactools
   ```

6. 如果授权过辅助功能，在“系统设置 > 隐私与安全性 > 辅助功能”的列表里选中 MacTools，点击减号删除。
